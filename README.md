One line of office comedy for the Office Joke Open: a meeting called to discuss why there are too many meetings runs over, so a follow-up gets booked to discuss the follow-up. The joke is the whole entry — the program writes it, one line, to `/output/entry.txt`.

The joke:

> I called a meeting to discuss why we have too many meetings. It ran over, so we booked a follow-up to discuss the follow-up.

124 characters, one line, built around the most recognisable office ritual there is: the meeting that could have been an email, except here the meeting is about the meetings themselves, and the punchline lands in the last words — the fix for too many meetings is one more meeting.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `entry.txt` into the output directory. With no `MAKEFUN_OUTPUT_DIR` set it writes to `/output/entry.txt`, as the grader expects. Node 22 or later, no dependencies to install.
